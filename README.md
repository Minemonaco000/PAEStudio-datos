# Datos públicos de Mi ingreso

Este repositorio contiene únicamente datos de admisión y el monitor de fuentes oficiales de PAEStudio SpA. No contiene preguntas, cuentas, puntajes ni progreso de estudiantes.

El catálogo y las tablas son instantáneas verificadas. La revisión diaria puede señalar cambios pendientes sin incorporarlos todavía. La fecha de consulta de fuentes no certifica por sí sola la vigencia de los datos.

Una modificación del catálogo o tablas requiere revisión editorial documentada en `admissions/feed-review.json`, con los SHA-256 de ambos archivos. El manifiesto de `public/` tiene secuencia creciente y referencias a archivos inmutables.
